# Wordly Usage Dashboard: Getting Started

## What it is

The Wordly Usage Dashboard turns the usage reports from your Wordly account into charts and tables you can explore: minutes used, sessions, attendees, languages, and remaining balances.

It's a single file that opens in your web browser. There's nothing to install and no account to create.

**Your data stays on your computer.** The dashboard reads your report files locally. Nothing is uploaded to Wordly or anywhere else.

## What you need

| Item | Details |
| --- | --- |
| The dashboard file | **Wordly Usage Dashboard.html**, sent to you by your Wordly team. |
| A web browser | **Google Chrome** or **Microsoft Edge** work best. |
| Usage reports | Excel files (.xlsx) exported from the Wordly portal. You need at least one; if your organization has several logins, include a report for each. |
| Admin Transaction report (optional) | Also from the Wordly portal. Add it to see each account's remaining minutes and purchase history. |

If you're not sure where to find these reports, your Wordly contact can send them to you or show you where to export them.

## Create your first dashboard

1. **Save the file.** Put **Wordly Usage Dashboard.html** somewhere easy to find, such as your Documents folder. Always open it from the same place.
2. **Open it.** Double-click the file. It opens in your web browser on the **Create a usage dashboard** screen.
    - If it opens in a different program, right-click the file, choose **Open with**, and pick Chrome or Edge.
3. **Enter a name.** Type your organization's name in **Customer name**. This is how your saved dashboards are labeled.
4. **Add your reports.** Drag your report files onto the **Drop report files here** box, or click **Choose files**. You can add several files at once.
5. **Check the file list.** Each file is labeled **Usage report** or **Transaction report**. A file marked as not recognized will be skipped; see Troubleshooting.
6. **Click Build dashboard.** Your dashboard appears in a few seconds.

The dashboard isn't saved yet at this point. See **Save and update your dashboard** below to keep it.

## Find your way around

Use the tabs under your organization's name to switch views.

| Tab | What it shows |
| --- | --- |
| Overview | Totals for minutes, sessions, attendees, and events, plus charts by month, account, and language. |
| Accounts | Each account's purchased minutes, minutes used, and remaining balance. Appears only when you add the Admin Transaction report. |
| Events | Your sessions grouped by title, with the languages attendees used. Click an event for details. |
| Session detail | Every session in a table you can search, sort, and filter. |
| Event timeline | Which sessions ran at what time of day, one row per event and one section per day. |

**Narrow it down.** The filter bar above the tabs applies to every tab:

- **From** and **To** limit the dashboard to a date range. Add times to focus on part of a day.
- **Quick range** picks common ranges, like the last 30 days or a single month.
- **Time zone** shows all times in the zone you choose, for example your own office's.
- **Workspace** and **Event** appear when your reports include them.

**Minutes or hours.** Use **View in minutes** or **View in hours** in the blue bar to switch every number on the page.

**Group sessions into one event.** On the **Events** tab, click **Group sessions into an event** to combine sessions with different titles, such as the days or rooms of one conference. The group then appears in the **Event** filter.

## Save and update your dashboard

Each time you save, the dashboard is stored as a **version** with the date and time, for example "Saved Nov 5, 2026 at 4:12 PM." Older versions stay available, so you can compare periods.

**Save a version**

1. Click **Save version** in the blue bar.
2. Check the name and click **Save version**.

**Add a new version when you have new reports**

1. Click **New dashboard** to return to the start screen.
2. In **Saved dashboards** on the right, click **Add new version** next to your organization's name.
3. Add your new report files and click **Build dashboard**.
4. Click **Save version**.

**Open a saved version**

- From the start screen, click any date under **Saved dashboards**.
- From inside a dashboard, pick one from the **Saved versions** list on the right.

Saved versions are kept in the browser you used to save them, on that computer. See the next section to keep a copy elsewhere.

## Share and back up

**Share a dashboard with a colleague.** Click **Download file** in the blue bar. This creates a single web page with the dashboard's data built in. Email it or put it on a shared drive; your colleague double-clicks it to view the dashboard and use the filters. It's read-only, and it shows the data as it was when you downloaded it.

**Back up a saved version.** On the start screen, click **Download backup** under any saved version. Keep the file somewhere safe, such as a shared drive.

**Open a backup.** On the start screen, click **Open a backup file** and choose the file. The version opens and is added to your saved dashboards.

Back up versions you care about, especially before clearing your browser's history or moving to a new computer.

## Troubleshooting

| If you see | Try this |
| --- | --- |
| The file opens as text or code | Right-click the file, choose **Open with**, and pick Chrome or Edge. |
| A file is marked "isn't a recognized report" | Use the original Excel file exported from the Wordly portal, without editing or re-saving it in another format. |
| "No sessions could be read" | Check that you added a Usage report, not only the Transaction report. The details shown on screen list what was found in each file. |
| My saved versions are gone | Versions are kept per browser and per computer. Open the file in the browser you saved them in, or use **Open a backup file**. |
| "Saving isn't available in this browser" | Switch to Chrome or Edge. Some browsers, including Safari, can block saving for files opened from your computer. |
| The **Accounts** tab is missing | Add the Admin Transaction report along with your Usage reports, then build again. |
| Totals differ slightly from the portal | Sessions with zero billed minutes aren't counted in totals. With a Transaction report, sessions that can't be matched to a charge are listed in a note at the top. |

**Does Wordly see my data?** No. The dashboard runs entirely in your browser and never sends your reports anywhere.
